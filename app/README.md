# Outlet Intelligence Web App

The Round 2 Outlet Intelligence Web App will provide an enterprise decision-support interface for outlet potential, spatial intelligence, spend allocation, and XAI explanations.

Expected local run command:

```bash
streamlit run app/streamlit_app.py
```

Planned features:

- Browse predictions
- Filter by distributor/province
- Outlet drilldown
- Budget allocation view
- XAI explanation panel
